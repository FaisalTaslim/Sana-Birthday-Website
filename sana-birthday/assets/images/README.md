# Drop photos here

The site looks for these filenames (referenced in `js/data.js`).
Add a file with the matching name and it appears automatically —
no code changes needed.

Timeline (Memory Lane section):
- memory-01.jpg
- memory-02.jpg
- memory-03.jpg

Gallery section:
- gallery-01.jpg
- gallery-02.jpg
- gallery-03.jpg
- gallery-04.jpg
- gallery-05.jpg
- gallery-06.jpg

Want a different number of photos? Add or remove entries in the
`timeline` and `gallery` arrays inside `js/data.js` — just make
sure each entry's `image` filename matches a file you add here.

Any common web image format works (.jpg, .png, .webp) — just
update the filename in `data.js` to match the extension you use.
